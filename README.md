# Honu

Honu is the Surf Shack Properties communications hub: guest and owner messages, ShackAI drafts, approvals, alerts,
reviews and phones in one staff page. This repository holds the new Honu (PostgreSQL + Node.js on SiteGround, at
honunui.surfshackproperties.com), built for multiple companies with Surf Shack Properties first.

- The plan this code is built from is in `docs/spec/` (part 2 v0.6.9, approved by Spencer on 2026-10-23).
- Coding rules: `docs/spec/08_coding_rules.md`. Test plan: `docs/spec/07_test_plan.md`.
